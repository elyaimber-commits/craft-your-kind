
# מסך ניהול פגישות לטיפול

## הרעיון

לכל פגישה שכבר נערכה (תאריך עבר) יש 3 צירים בלתי תלויים:

| ציר | מתי נחשב "✓" |
|-----|---------------|
| **סוכמה** | קובץ סיכום הועלה לתיקיית ה-Drive של המטופל/ת |
| **שולמה** | קיים `paid_event_ids` שמכיל את ה-event הזה ב-`payments` |
| **חשבונית** | קיים `external_payment_id` (Green Invoice) על אותו תשלום |

הצבע הצהוב בלוח השנה האמיתי של Google מסמן: **נערכה אך לא סוכמה**. ברגע שהסיכום עולה ל-Drive — הצבע מתעדכן (נשאר אדום=לא שולם, או ירוק=שולם, לפי הלוגיקה הקיימת).

## המסך החדש: "פגישות לטיפול"

טאב חדש בדאשבורד הראשי עם רשימה אחת חכמה של כל הפגישות מהעבר שחסר להן משהו. לכל פגישה — שורה עם 3 צ'יפים סטטוס + פעולות מהירות.

```text
┌────────────────────────────────────────────────────────────┐
│ פגישות לטיפול  [12]                    [סינון ▾] [מטופל ▾] │
├────────────────────────────────────────────────────────────┤
│ דנה כהן · ה׳ 2/5/26 16:00          ❌סיכום ❌תשלום ❌חשב׳  │
│   [🎙 סכם]  [💰 סמן כשולם]  [🧾 הפק חשבונית]              │
├────────────────────────────────────────────────────────────┤
│ יוסי לוי · ד׳ 1/5/26 10:00         ✅סיכום ❌תשלום ❌חשב׳  │
│   [💰 סמן כשולם]  [📱 בקש בוואטסאפ]                       │
├────────────────────────────────────────────────────────────┤
│ מיה אבן · ג׳ 30/4/26 18:00         ❌סיכום ✅תשלום ❌חשב׳  │
│   [🎙 סכם]  [🧾 הפק חשבונית]                              │
└────────────────────────────────────────────────────────────┘
```

**סינונים:** הכול / חסר סיכום / חסר תשלום / חסר חשבונית / מטופל מסוים.
**ברירת מחדל:** מציג פגישות מ-30 יום אחרונים שחסר להן משהו אחד לפחות.

## צביעה אוטומטית ביומן Google

כל פגישה שעברה מקבלת צבע אוטומטית לפי המצב הצירופי:

| מצב | צבע ביומן |
|-----|-----------|
| לא סוכמה + לא שולמה | **🟡 צהוב** (חדש) |
| סוכמה + לא שולמה | 🔴 אדום (קיים) |
| לא סוכמה + שולמה | 🟠 כתום (חדש) |
| סוכמה + שולמה | 🟢 ירוק (קיים) |

המערכת תפעיל סנכרון צבעים אוטומטי ברקע כל פעם ש:
- סיכום נשמר ל-Drive (אירוע אחד)
- תשלום נרשם / חשבונית התקבלה ב-webhook
- המשתמש פותח את הדאשבורד (סנכרון של כל מה שעבר ב-7 ימים אחרונים)

## פרטים טכניים

### זיהוי "סוכמה"
שינוי קל ב-`google-drive-upload`: בעת העלאה מוצלחת, להחזיר את `eventId` (יועבר מהדיאלוג) ולשמור רשומה בטבלה חדשה `session_summaries`:

```sql
CREATE TABLE session_summaries (
  id uuid PK,
  therapist_id uuid,
  patient_id uuid,
  event_id text,        -- Google Calendar event ID
  drive_file_id text,
  drive_file_name text,
  created_at timestamptz
);
-- + RLS לפי therapist_id, UNIQUE(therapist_id, event_id)
```

מקור אמת לסטטוס סיכום = קיום שורה בטבלה הזו (לא תלוי ב-Drive עצמו, כי שאילתת Drive לכל אירוע איטית מדי).

### זיהוי "שולמה" / "חשבונית"
כבר קיים: `payments.paid_event_ids[]` ו-`payments.external_payment_id`. רק לקרוא — אין שינוי סכימה.

### צביעה אוטומטית
פונקציית edge חדשה `auto-color-events` שמקבלת רשימת `eventIds` (או "כל החודש"), מחשבת לכל אחד את הצבע הנכון, ומריצה batch update דרך Google Calendar API. נקרא:
- מ-`google-drive-upload` אחרי שמירת סיכום (אירוע יחיד)
- מ-`green-invoice-webhook` אחרי תשלום (אירועים שב-`paid_event_ids`)
- מ-Dashboard בטעינה (דה-באונס ל-7 ימים אחרונים)

### הדף החדש
- קומפוננטה: `src/components/SessionsToHandle.tsx`
- שולפת אירועים דרך `google-calendar-events` (קיים), מצליבה עם `session_summaries` + `payments`, מסננת רק `start < now` ושחסר משהו.
- כל פעולה (סכם / סמן שולם / הפק חשבונית) פותחת את הדיאלוג הקיים המתאים.
- מיקום: טאב חדש ב-Dashboard בשם "**לטיפול**" (עם badge מספרי), כברירת מחדל מסומן אם יש >0.

## סדר הביצוע

1. הוספת טבלת `session_summaries` + RLS.
2. עדכון `SessionNoteRecorderDialog` להעביר `eventId`, ועדכון `google-drive-upload` לרשום סיכום.
3. פונקציית `auto-color-events` + הוספת צבעים צהוב/כתום ל-mapping הקיים.
4. קריאה ל-`auto-color-events` מתוך `google-drive-upload` ו-`green-invoice-webhook`.
5. קומפוננטת `SessionsToHandle` + טאב חדש בדאשבורד עם badge.
6. סנכרון צבעים ברקע בטעינת הדאשבורד (7 ימים אחורה).

## הערות

- אם בעתיד תרצה גם "חשבונית לפני תשלום" — אפשר להוסיף, אבל כרגע לפי החלטתך חשבונית = רק אחרי תשלום, אז הציר השלישי פשוט יורש את לוגיקת התשלום + Green Invoice.
- אם פגישה מסוכמת אבל המטופל ב-billing חודשי — היא עדיין תופיע ב"לטיפול" עד שיגיע התשלום החודשי שמכסה אותה.
