# שמירה אוטומטית ל-WD My Cloud Home

## האם זה אפשרי? כן — אבל עם אזהרות חשובות

ל-WD My Cloud Home יש API רשמי (`developer.westerndigital.com`). אפשר להתחבר אליו ולהעלות קבצים ישירות לתיקיית מטופל מסוימת. אך יש כמה דברים שחשוב להבין **לפני** שאני בונה:

### 1. אבטחה — מאוד חשוב
ה-API דורש את **סיסמת חשבון ה-WD שלך** (אימייל + סיסמה דרך Auth0). אין מנגנון של "אסימון רק לתיקייה אחת" — מי שמחזיק באישורים יקבל גישה לכל ה-Cloud Home שלך.
המשמעות: הסיסמה תישמר כסוד באדג'-פונקשן בענן. זה סביר אם רק את/ה משתמש/ת באפליקציה, אבל זה **לא** סטנדרט מומלץ.

### 2. מיפוי מטופל → תיקייה
לכל תיקייה ב-WD יש `folderId` פנימי (לא נתיב טקסטואלי). נצטרך טבלה קטנה במסד הנתונים שמקשרת `patient_id → wd_folder_id`. הגדרה ראשונית תיעשה דרך מסך הגדרות חדש שיציג את עץ התיקיות שלך ויאפשר לבחור תיקייה לכל מטופל.

### 3. PWA באייפון — שיקול חשוב
ה-API של WD חוסם CORS, לכן ההעלאה תעבור דרך אדג'-פונקשן (לא ישירות מהדפדפן). זה אומר: הקובץ נוסע מהאייפון → השרת שלנו → WD. עובד תקין, אבל עדכון ה-PWA חייב להיעשות (אותה בעיית cache שהיתה).

## תהליך משתמש מוצע

**הגדרה חד-פעמית (מסך חדש "אחסון WD"):**
1. הזנת אימייל + סיסמת WD My Cloud Home + שם המכשיר.
2. בחירת תיקיית-בסיס (למשל `/Therapy/Patients/`).
3. לכל מטופל: בחירת תת-תיקייה ייעודית מתוך רשימה שנמשכת מה-WD.

**זרימה רגילה (אחרי תמלול):**
1. בדיאלוג סיכום הפגישה, ליד "הורד כ-TXT" יתווסף כפתור **"שמור ל-WD"** (פעיל רק אם למטופל מוגדרת תיקייה).
2. לחיצה → הקובץ `שם-מטופל_תאריך.txt` נשלח לאדג'-פונקשן → מועלה לתיקייה הנכונה ב-WD.
3. הודעת הצלחה/כישלון.
4. הורדה לאייפון תישאר זמינה במקביל (לא במקום).

## חלקים טכניים

**טבלאות חדשות:**
- `wd_settings` — שורה אחת למשתמש: `device_id`, `base_folder_id`, סטטוס חיבור.
- `wd_patient_folders` — `patient_id` → `wd_folder_id` (UNIQUE על patient_id).
- RLS מלא: רק המשתמש רואה את השורות שלו.

**סודות:**
- `WD_USERNAME`, `WD_PASSWORD` — אבקש להזין דרך כלי הסודות.

**אדג'-פונקשנים חדשים:**
- `wd-auth` — מבצע OAuth מול Auth0 של WD ומקבל access token (cache קצר ב-RAM של הפונקציה).
- `wd-list-folders` — מחזיר עץ תיקיות לבחירה במסך ההגדרות.
- `wd-upload` — מקבל `{ patient_id, filename, content }`, מאתר את התיקייה ומעלה.
- כולם עם ולידציית JWT (`getClaims`) כמו שאר הפונקציות.

**שינויי UI:**
- מסך הגדרות חדש `/settings/wd-storage` (קישור מה-Dashboard).
- ב-`PatientBillingCard` ליד שם המטופל: indicator קטן אם יש תיקיית WD מוגדרת.
- ב-`SessionNoteRecorderDialog`: כפתור "שמור ל-WD" + מצב טעינה + טוסט.

## חלופה פשוטה יותר — להמליץ עליה?
אם תרצה, נוכל להתחיל בגישה הרבה יותר פשוטה:
**שיתוף ידני ל-Files iOS.** ה-iPhone יודע לשתף קובץ ישירות ל-My Cloud Home דרך אפליקציית Files. נוסיף כפתור "שתף" שיפעיל את ה-share sheet של iOS, ותוכל בקליק אחד לשמור לתיקיית המטופל. **אין סודות, אין API, אין מסך הגדרות.** החיסרון: אתה בוחר את התיקייה ידנית בכל פעם (אבל iOS זוכר את התיקיה האחרונה).
